# Phase 5 設計: タイムライン(ガント)ビュー

状態: 実装済み(2026-11-03)。

## 1. 目的
DB ビュー(Table・Board・Calendar)に、期間と前後関係を見るためのタイムライン(`view: timeline`)を足す。Notion の Timeline と同じことができる水準を目標にする。

## 2. 決めたこと
- **期間は `start` と `due`。** 終わりは既存の `date`(既定 `due`)を使い、始まりのキー `start`(既定 `start`)を足す。start が無い行は due の 1 日の横棒になる。Board・Calendar・memo-mcp の `due` の意味は変えない。
- **書く範囲。** 基本の操作に加えて、依存関係の矢印・サブアイテム・プロジェクト単位の集約を入れる。
  - 基本の操作:横棒の移動と伸縮、5 段のズーム、左の表、今日の線、日付の無い行への日付付け、空き段のドラッグでの作成、グループ化。
- **依存は `blockedBy`(ページへのリンクのリスト)。**
  - データベースのプロパティ型に `pages` を足した(`database.define` の Lua 検証、`databaseFrom`、表のセル)。
  - 依存の矢印はページの行だけに引く(チェックボックス行の ref は編集で変わるため)。
- **サブアイテム。**
  - ページは `parent`(リンク)で、チェックボックス行は索引の `parent`(字下げの親)で親子にする。
  - 親子が輪になっているときは、輪の行をすべて上の段に置く。
- **プロジェクトの集約。**
  - `source: projects`(または `tag: project`)のとき、`loadRows` はプロジェクトの配下を `ViewModel.children` として別に読む。配下とは、`project` でそのプロジェクトを指すページと、そのページのチェックボックス行。
  - `rows` には混ぜないので、Table・Board の件数は変わらない。
  - 日付の無いプロジェクトは、配下の最早 start〜最遅 due をハッチの横棒で出し、完了数/全数を添える。この横棒はドラッグしない。
- **連鎖。** 待たれている行を動かして後続と重なったら、後続を「重なった分だけ」後ろへずらす(Notion の既定 "Shift only when dates overlap" と同じ考え方)。輪は 1 度だけたどる。移動と連鎖は 1 つの Undo で戻る。
- **書き込み。**
  - ページの行には、新しい `updatePageValues` を使う。stale の確認は 1 回、`index.patchFrontmatter` も 1 回で、複数のキーを書く。
  - チェックボックス行には、`updateTask` の `{type: "dates"}` を使う。`setTaskAttributes` が、行の `[start: …]` と `[due: …]` を置き換えるか、行末に足す。
  - 複数の行への書き込み(連鎖)は、runner の `writeMany` が 1 行ずつ順に行う。1 行でも失敗したらそこで止め、何行まで書けたかを伝えて読み直す。
  - 1 日だけの行(due だけ)は、2 日以上に伸ばされるまで start を書かない。
- **UI の規約。**
  - `tl.*` のイベントは `timeline_mediator.ts`(純関数 `transitionTimeline`)が裁く。`db_mediator.ts` は、`tl.` で始まるイベントをここへ渡すだけにする。
  - ポインタの扱いは `bar_drag.ts` が受け持つ(`pointer_drag.ts` と同じく、マウスはすぐ、タッチは長押しで始める)。
  - ドラッグが始まったら、押した要素がポインタを捕まえる。フレームの外で離しても、ドラッグはきちんと終わる。
  - スクロール位置、空き段のホバー、表の幅のドラッグは見た目だけの状態なので、部品の中に持つ(`timeline_view.tsx` の Rule note)。
- **Save view** は、`view` `sort` `filter` に加えて、Timeline の `zoom` と `group` を書き戻す。

## 3. 直した upstream の不具合
`plug-api/lib/yaml.ts` の `serializeToYamlScalar` には、特殊文字を判定する正規表現の文字クラス内に `]` がエスケープなしで入っていた。そのため文字クラスがそこで閉じ、`[[Page]]` が引用符なしで書かれていた。こう書かれた値は、YAML では入れ子のリストとして読まれる。表でページのセルを編集したときにも起きていた。`]` を 1 文字エスケープして直し、テストを足した。

## 4. 残したこと
- 行の手動の並べ替え(Notion のドラッグでの並び替え)は無い。並び順は、`sort` があればそれ、無ければ開始日の順(データベースのビューは名前の順)。
- ズームを変えると、表示は今日へ戻る(いま見ている日は保たない)。
- 依存の連鎖で、先行を前へ動かしても後続は前へは戻らない(Notion と同じ)。
