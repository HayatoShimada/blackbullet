Local-first · AI-native · Markdown

ローカルで動く、Markdown のノートアプリ

ノートは自分のフォルダの .md ファイルとして保存されます。意味検索、データベース表示、MCP による AI 連携つき。

Features

機能

ショートカットはコマンドパレット Ctrl-/ からいつでも確認できます。

Write

ブロックエディタ

ドラッグハンドルと折りたたみつきのブロック編集、ドラッグ&ドロップで並べ替えるページツリー、カバー画像とアイコン。すべての変更は Undo できます。

Ctrl-q q クイックノートCtrl-q j 日誌
Find

言葉と意味で探す

全ノートの見出し単位で、文字一致とローカル埋め込みモデルによる意味検索を一度に。開いているページの関連ノートと、リンクと類似度のグラフも。

Ctrl-q s 検索Ctrl-q r 関連Ctrl-Shift-g グラフ
Organise

データベース

型つきプロパティ・フォルダ・テンプレートを一度宣言すれば、表・ボード・カレンダーで表示してその場で編集。復元できるゴミ箱つき。

Ctrl-Alt-n New
Ask

ノートに質問する

自分のノートから引用つきで回答。追加質問や、回答をページとして保存することもできます。Anthropic の API キーが必要です。

Ctrl-q a Ask
Documents

PDF や Office も検索対象

フォルダに置いた PDF、Word、Excel、PowerPoint、OpenDocument、HTML も検索できます。OCR はオプションです。

MCP

AI アシスタントと共有

同じノートを Claude Code や Claude Desktop などの MCP クライアントから検索・追記できます。トークンや鍵を置く CONFIG は読めません。

Principles

データの扱い

ファイルが唯一の正本

ノートはフォルダの中の Markdown です。検索インデックスや埋め込みは消しても作り直せます。既存のノートフォルダをそのまま使えます。

手元で動く

アプリも検索も自分のマシンで動きます。ノート本文が外に出るのは、自分で Ask を実行したときだけ。:confidential を付けたスペースは許可しない限り送りません。

スマホからも

スマホ幅のレイアウトに対応。オプションの Tailscale 専用 HTTPS 入口を使えば、許可したログインだけがパスワード画面なしで開けます。

Install

インストール

必要なのは Docker と Compose v2 だけです。Rust や Node をホストに入れる必要はありません。

取得してセットアップを実行

$ git clone https://github.com/HayatoShimada/blackbullet.git
$ cd blackbullet
$ ./setup.sh

初回はイメージのビルドに 10〜20 分かかります(Raspberry Pi クラスのマシンの目安)。2 回目以降は起動するだけです。

ブラウザで開く

http://127.0.0.1:3000
  • ノートは ./space に保存されます。既存の Markdown フォルダを使うなら、setup.sh の前に .env へ SPACE_DIR=/path/to/notes を書きます。
  • 検索サイドカーも同時に起動・接続されます。最初の索引作成で約 120 MB の埋め込みモデルを一度だけ取得し、CPU で動かします。
  • ダウンロードしたくない場合は .env に MEMO_EMBED=off。検索は文字一致のみになります。

AI アシスタントをつなぐ(任意)

サイドカーは http://127.0.0.1:3010/mcp で MCP を話します。setup.sh がトークン入りのコマンドを表示するので、それを実行するだけです。

$ claude mcp add --scope user --transport http memo http://127.0.0.1:3010/mcp \
    --header "Authorization: Bearer <MEMO_MCP_TOKEN>"

使えるツール: search_notes read_note read_section related_notes list_tasks list_projects list_journal recent_changes append_journal add_inbox complete_task doc_status reindex_docs

Ask を使う(任意)

コマンドパレットで Ask: Set up を一度実行し、Anthropic の API キーをスペースの CONFIG に保存します。以後 Ctrl-q a で質問できます。#tag、in:Folder/、kind:pdf、since:2026-01-01 で範囲を絞れます。

日々の運用

コマンド内容
./setup.sh --statusアプリとサイドカーの状態、索引とモデルの状況、ディスク使用量
./setup.sh --backup [dir] [--with-secrets]ノートの .tar.gz を日時つきで作成(--with-secrets がなければ秘密情報は空にする)
./setup.sh --restore <file>安全のためのコピーを取ってから、バックアップをノートフォルダに統合
./setup.sh --upgradegit pull してビルドし直し、再起動
./setup.sh --tailnetTailscale ネットワーク内だけから届く HTTPS の入口を追加
./setup.sh --stopすべて停止。ノートはそのまま残ります

設定はすべて .env にあり、各項目の説明は .env.example にあります。アプリ内の使い方はヘッダーの ? ボタン(日本語ガイド)から。

v1.0.0 2026-10-03 Latest

BlackBullet 最初の本番リリース。SilverBullet 2.11 からフォークした、個人用・ローカルファースト・AI ネイティブのノートアプリです。

  • Setup./setup.sh 一発で検索 / MCP サイドカーごと起動。--status・--backup・--restore・--upgrade。
  • Databasedatabase.define によるデータベース。表・ボード・カレンダー表示、+ New、フィルタ、保存ビュー、行メニュー、復元できるゴミ箱。
  • Search言葉と意味による検索、関連ノート、類似ページのグラフ、引用つきで答える Ask。
  • DocsPDF / Office / OpenDocument / HTML 文書も検索対象に。
  • MCPAI アシスタント向け MCP サーバー。tailnet 専用 HTTPS 入口からも利用可能。
  • Designインターフェースを再設計。統一された用語、ひとつの New、すべての変更に Undo、一貫したキーボード操作、ライト / ダーク、スマホレイアウト。
  • LicenseGPL-2.0-only。SilverBullet の MIT 表記は NOTICE.md に収録。
